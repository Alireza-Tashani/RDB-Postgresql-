# 📘 سند استخراج موجودیت‌ها  
## سیستم مدیریت کتابخانه (Library Management System)


---

## 🎯 هدف
هدف این سند، شناسایی و تعریف موجودیت‌های اصلی سیستم مدیریت کتابخانه (LMS) است.  
در این مرحله، داده‌ها **بدون نرمال‌سازی** ارائه شده‌اند تا دید کلی نسبت به ساختار سیستم فراهم شود.  
این مستند پایه‌ای برای طراحی **ERD (Entity Relationship Diagram)** خواهد بود.

---

## 🧩 فهرست موجودیت‌ها
1. **Book (کتاب)**  
2. **Author (نویسنده)**  
3. **Publisher (ناشر)**  
4. **Category (دسته‌بندی)**  
5. **Member (عضو)**  
6. **Loan (امانت)**  

---

## 📙 1. Book (کتاب)
نماینده‌ی هر کتاب موجود در کتابخانه است. شامل اطلاعات کلی درباره‌ی نسخه‌های کتاب.

**ویژگی‌ها:**
| نام فیلد | نوع داده (پیشنهادی) | توضیح |
|-----------|----------------------|--------|
| `id` | INT (PK) | شناسه یکتا کتاب |
| `title` | VARCHAR | عنوان کتاب |
| `publishyear` | YEAR | سال انتشار |
| `total_number` | INT | تعداد کل نسخه‌های موجود |
| `available_number` | INT | تعداد نسخه‌های فعلاً در دسترس |

---

## 📗 2. Author (نویسنده)
اطلاعات نویسندگان کتاب‌ها را نگهداری می‌کند.

**ویژگی‌ها:**
| نام فیلد | نوع داده (پیشنهادی) | توضیح |
|-----------|----------------------|--------|
| `id` | INT (PK) | شناسه یکتا نویسنده |
| `fname` | VARCHAR | نام نویسنده |
| `lname` | VARCHAR | نام خانوادگی نویسنده |

---

## 📘 3. Publisher (ناشر)
نمایانگر ناشران کتاب‌ها.

**ویژگی‌ها:**
| نام فیلد | نوع داده (پیشنهادی) | توضیح |
|-----------|----------------------|--------|
| `id` | INT (PK) | شناسه یکتا ناشر |
| `name` | VARCHAR | نام ناشر |
| `city` | VARCHAR | شهر محل فعالیت ناشر |
| `phone` | VARCHAR | شماره تماس ناشر |

---

## 📒 4. Category (دسته‌بندی)
دسته‌های موضوعی کتاب‌ها را مشخص می‌کند (مثلاً علمی، تاریخی، ادبی).

**ویژگی‌ها:**
| نام فیلد | نوع داده (پیشنهادی) | توضیح |
|-----------|----------------------|--------|
| `id` | INT (PK) | شناسه یکتا دسته |
| `title` | VARCHAR | عنوان دسته‌بندی |

---

## 📕 5. Member (عضو)
اطلاعات اعضای کتابخانه که کتاب امانت می‌گیرند.

**ویژگی‌ها:**
| نام فیلد | نوع داده (پیشنهادی) | توضیح |
|-----------|----------------------|--------|
| `id` | INT (PK) | شناسه یکتا عضو |
| `fname` | VARCHAR | نام عضو |
| `lname` | VARCHAR | نام خانوادگی عضو |
| `phone` | VARCHAR | شماره تماس |
| `register_date` | DATE | تاریخ عضویت |
| `status` | ENUM('active','inactive') | وضعیت عضویت |
| `total_fine` | DECIMAL | میزان کل جریمه‌های پرداخت‌نشده |

---

## 📙 6. Loan (امانت)
نماینده‌ی تراکنش امانت گرفتن کتاب توسط اعضاست.

**ویژگی‌ها:**
| نام فیلد | نوع داده (پیشنهادی) | توضیح |
|-----------|----------------------|--------|
| `id` | INT (PK) | شناسه یکتا امانت |
| `bookid` | INT (FK → Book.id) | شناسه کتاب امانت داده‌شده |
| `memberid` | INT (FK → Member.id) | شناسه عضو امانت‌گیرنده |
| `issue_date` | DATE | تاریخ تحویل کتاب |
| `due_date` | DATE | تاریخ موعد بازگشت |
| `return_date` | DATE | تاریخ بازگشت واقعی |
| `fine_amount` | DECIMAL | جریمه مربوط به این امانت (در صورت تأخیر) |

---

## 🔗 روابط بین موجودیت‌ها (در سطح مفهومی)

| موجودیت 1 | موجودیت 2 | نوع رابطه | توضیح |
|------------|------------|-------------|--------|
| `Book` | `Author` | M:N | هر کتاب می‌تواند چند نویسنده داشته باشد، و هر نویسنده می‌تواند چند کتاب بنویسد. |
| `Book` | `Publisher` | N:1 | هر کتاب متعلق به یک ناشر است. |
| `Book` | `Category` | N:1 | هر کتاب در یک دسته‌بندی خاص قرار دارد. |
| `Book` | `Loan` | 1:N | هر کتاب می‌تواند چند بار امانت داده شود. |
| `Member` | `Loan` | 1:N | هر عضو می‌تواند چند کتاب امانت بگیرد. |
